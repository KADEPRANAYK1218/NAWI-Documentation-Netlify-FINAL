# SIH26035 — NAWI Test Report Generation System

## Project Overview

**SIH26035** is a student-built software prototype for the **generation of Test Reports for Non-Automatic Weighing Instruments (NAWI)** in accordance with applicable requirements of **OIML Recommendation R 76** and the Indian **Legal Metrology** framework.

The platform brings instrument registration, test configuration, measurement entry, automated calculations, test-result evaluation, report generation, record management and system controls into a single digital application.

## Project Architecture

The system is organized into a React-based frontend, Node.js/Express backend, structured instrument and test data, reusable interface components and automated report-generation functionality.

## Key Features

* NAWI instrument registration
* Instrument and manufacturer details
* Test configuration
* OIML R 76-based test workflow
* Measurement and observation entry
* Accuracy/error calculations
* Repeatability testing
* Eccentricity/corner-load testing
* Increasing/decreasing load testing
* Permissible-error evaluation
* Pass/fail result generation
* Test history and digital records
* Automated test-report generation
* PDF report generation
* Inspector and verification details
* Settings and system management

## Project Goals

* Digitize the testing workflow for Non-Automatic Weighing Instruments.
* Reduce manual calculations and repetitive data entry.
* Provide structured and consistent recording of test observations.
* Automatically calculate and evaluate relevant test results.
* Generate standardized digital test reports.
* Support workflows based on OIML R 76 and the Indian Legal Metrology framework.
* Provide a modular foundation that can be expanded for official or departmental systems.

The uploaded SIH26035 prototype demonstrates the core digital workflow for NAWI testing, including instrument information, test setup, measurement entry, calculations, test-result evaluation and automated report generation.

> **Note:** The current project is a student prototype. It is intended for demonstration and development purposes and should not be treated as an officially approved Legal Metrology verification or certification system.
